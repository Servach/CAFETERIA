# Cafecita

Sitio web de Cafecita, una cafetería de barrio. Es HTML, CSS y JavaScript sin dependencias.

Para verlo, abre `index.html` en el navegador.

- `index.html`: la página
- `css/styles.css`: estilos (paleta y tipografías del brandboard)
- `js/main.js`: menú con pestañas, ficha de bebidas, test "¿Cómo vienes hoy?" y horario en vivo
- `assets/img/`: logo, ilustraciones y fotos

Datos de ejemplo por reemplazar: dirección, mapa, horario, WhatsApp y redes sociales.
